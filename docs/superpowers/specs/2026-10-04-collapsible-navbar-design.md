# 스크롤 반응형 Navbar 디자인

## 목표

메인페이지와 퇴행성 무릎관절염 페이지의 데스크톱 navbar에 동일한 축소 동작을 적용한다. 페이지를 내리면 하단 카테고리 줄을 접어 콘텐츠 영역을 넓히고, 사용자가 navbar를 가리키면 카테고리 줄을 다시 표시한다.

## 동작

- 페이지 최상단에서는 카테고리 줄을 항상 표시한다.
- 데스크톱에서 스크롤 위치가 80px을 넘으면 헤더에 축소 상태를 적용한다.
- 축소 상태에서는 카테고리 줄의 높이와 투명도를 부드럽게 줄이고 포인터 입력을 막는다.
- 축소된 헤더에 마우스를 올리거나 내부 요소에 키보드 포커스가 들어오면 카테고리 줄을 펼친다.
- 마우스와 포커스가 벗어나면 스크롤된 상태에서 다시 접는다.
- 화면 너비 800px 이하에서는 기존 햄버거 메뉴 동작을 유지하며 축소 효과를 적용하지 않는다.
- 모션 감소 설정에서는 전환 시간을 제거한다.

## 구현

- 각 페이지의 기존 스크립트가 스크롤과 창 크기 변화를 감지해 `.site-header`의 `is-nav-collapsed` 클래스를 관리한다.
- CSS의 `:hover`와 `:focus-within`을 이용해 별도의 포인터 이벤트 없이 일시적으로 펼친다.
- 메인페이지와 관절염 페이지는 같은 임계값과 전환 시간을 사용한다.

## 확인 기준

- 두 페이지 모두 80px 아래에서 카테고리 줄이 접힌다.
- 헤더 hover 및 키보드 포커스 시 카테고리 줄이 나타난다.
- 페이지 상단으로 돌아오면 hover 여부와 관계없이 카테고리 줄이 유지된다.
- 모바일 햄버거 메뉴를 열고 닫을 수 있다.
