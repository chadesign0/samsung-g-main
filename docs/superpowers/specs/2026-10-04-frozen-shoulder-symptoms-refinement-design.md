# 오십견 증상 섹션 정교화 설계

## 목표

사용자가 제공한 증상 섹션 시안을 기준으로 오십견 페이지의 배경 이미지와 증상 박스 스타일을 재현한다.

## 적용 방식

- 배경은 제공된 `Group 107.png`를 페이지 전용 에셋으로 복사해 사용한다.
- 이미지에 이미 적용된 암부 처리와 관절 하이라이트를 유지하고, 별도의 강한 그라데이션은 제거한다.
- 데스크톱 내용은 시안처럼 왼쪽 고정 영역에 제목, 설명, 4개 증상 박스 순으로 배치한다.
- 증상 박스는 부드러운 회색 반투명 배경, 얇은 흰색 테두리, 작은 모서리 둥글기를 사용한다.
- 체크 아이콘은 정사각형 외곽선 안에 체크가 있는 형태로 유지하고, 텍스트와의 간격을 시안에 맞춘다.
- 모바일에서는 배경 핵심 부위를 상단에 보여준 뒤 텍스트와 박스가 세로로 이어지는 현재 구조를 유지한다.

## 검증

- 1280px 데스크톱과 390px 모바일에서 시각 검수한다.
- 배경 이미지 누락, 가로 넘침, 콘솔 오류를 확인한다.
