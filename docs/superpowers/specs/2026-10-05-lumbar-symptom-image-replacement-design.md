# 허리디스크 증상 이미지 교체 디자인

## 목표

허리디스크 증상 섹션의 배경과 디스크 확대 원형을 새 디자인 원본 `Group 114.png`와 동일하게 표시한다.

## 변경 범위

- `Group 114.png`를 허리디스크 전용 웹 자산으로 복사해 증상 섹션 배경으로 사용한다.
- 새 이미지에 이미 포함된 어두운 오버레이와 디스크 확대 원형을 그대로 사용한다.
- 기존 CSS로 합성하던 `.disc-focus` 원형 요소와 관련 스타일을 제거해 중복 표시를 없앤다.
- 제목, 2×2 증상 박스, 순차 등장 효과와 모바일 1열 배치는 유지한다.
- CSS 캐시 버전을 올려 브라우저에서 새 이미지를 즉시 불러오게 한다.

## 검증

- 데스크톱에서 확대 원형이 한 번만 표시되고 새 원본 위치와 일치하는지 확인한다.
- 모바일에서 배경 중심부와 증상 박스가 잘리지 않고 가로 스크롤이 생기지 않는지 확인한다.
- 이미지 로딩과 브라우저 콘솔 오류를 확인한다.
