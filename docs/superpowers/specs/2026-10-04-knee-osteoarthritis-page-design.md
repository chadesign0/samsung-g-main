# 퇴행성 무릎관절염 상세 페이지 디자인

## 목표

첨부된 1920px Figma 시안을 기존 삼성G정형외과 정적 사이트의 새 질환 상세 페이지로 구현한다. 모든 본문 텍스트와 링크는 실제 HTML로 제공하고, 제공된 로컬 이미지를 해당 디자인 슬롯에 그대로 사용한다.

## 구조

- 페이지: `pages/knee-osteoarthritis.html`
- 전용 스타일: `pages/knee-osteoarthritis.css`
- 전용 동작: `pages/knee-osteoarthritis.js`
- 이미지: `assets/subpages/knee-osteoarthritis/`
- 기존 로고, 국기, 상담 배경과 푸터 자산은 현재 프로젝트 자산을 재사용한다.

## 화면 섹션

1. 기존 서브페이지 패턴을 따르는 2단 헤더와 모바일 메뉴
2. 무릎 통증 합성 이미지, 경로 표시, 제목, 설명, 질환 탭이 포함된 히어로
3. 퇴행성 변화의 네 가지 원인을 4열 단일 카드로 보여주고, 호버·포커스·탭 시 설명을 펼치는 원인 섹션
4. 대형 무릎 이미지와 네 가지 증상 설명을 배치한 진한 남색 증상 섹션
5. 약물치료, 물리·운동치료, 주사치료를 교차형 카드로 구성한 치료 섹션
6. 기존 상담문의와 푸터 패턴

## 반응형 동작

- 데스크톱에서는 Figma의 1200px 콘텐츠 폭과 넓은 여백을 유지한다.
- 태블릿에서는 카드와 치료 행의 간격을 축소한다.
- 모바일에서는 헤더 메뉴를 토글형으로 전환하고, 원인 카드는 2열, 치료 행은 1열 스택으로 바꾼다.
- 증상 섹션은 중앙 무릎 이미지를 유지하면서 설명을 이미지 아래 2열 카드로 재배치해 가독성을 보장한다.

## 상호작용 및 접근성

- 메뉴 토글의 `aria-expanded` 상태를 동기화한다.
- 질환 탭에는 현재 항목을 `aria-current="page"`로 표시한다.
- 원인 카드는 호버·키보드 포커스·모바일 탭 시 어두운 오버레이가 깔리고 제목이 위로 이동하며 설명이 나타난다.
- 의미 있는 이미지는 한국어 대체 텍스트를 사용하고 장식 요소는 접근성 트리에서 제외한다.

## 검증

- 로컬 서버에서 페이지, CSS, JS와 모든 이미지가 HTTP 200으로 응답하는지 확인한다.
- 데스크톱 및 모바일 뷰포트에서 섹션 순서, 겹침, 잘림과 가로 스크롤을 점검한다.
- 브라우저 콘솔 오류와 깨진 이미지가 없는지 확인한다.
