# 증상 섹션 순차 애니메이션 디자인

## 목표

퇴행성 무릎관절염 페이지의 증상 1~4가 아래에서 올라오지 않도록 한다. 각 화살표는 무릎 이미지 중앙 쪽 시작점에서 바깥쪽 끝을 향해 뻗고, 숫자와 텍스트는 기존 위치를 유지한 채 나타난다.

## 동작

- 섹션이 화면에 들어오면 1번부터 4번까지 순서대로 재생한다.
- 각 항목은 0.2초 간격으로 시작한다.
- 화살표는 중앙 쪽 끝을 기준으로 약 0.55초 동안 길이가 늘어난다.
- 숫자, 제목, 설명은 이동하지 않고 같은 순서로 페이드인한다.
- 제목 영역과 다른 섹션의 기존 `reveal` 효과는 유지한다.
- `prefers-reduced-motion` 사용자는 모든 요소를 즉시 표시한다.

## 구현 범위

- 증상 항목에 전용 표시 클래스를 사용해 공통 `reveal`의 세로 이동 효과와 분리한다.
- 화살표 의사 요소의 기존 방향 변환을 CSS 변수로 보존하고, 중앙 쪽을 `transform-origin`으로 지정한다.
- JavaScript의 기존 `IntersectionObserver` 흐름은 유지하며 전용 증상 항목도 동일한 시점에 관찰한다.
- 현재 위치, 크기, 문구 및 반응형 레이아웃은 변경하지 않는다.
- 데스크톱에서 1·2번 숫자를 위로 옮긴 30px만큼 제목의 상단 간격을 보정해 3·4번과 동일한 시각적 간격을 유지한다.
- 모바일에서는 네 항목 모두 동일한 기본 숫자·제목 간격을 사용한다.

## 확인 기준

- 데스크톱에서 화살표가 중앙에서 네 방향 바깥쪽으로 순서대로 뻗는다.
- 숫자와 텍스트에 세로 이동이 없다.
- 1→2→3→4 순서가 명확하다.
- 모바일에서 숨겨진 화살표 때문에 빈 애니메이션 지연이 생기지 않고 항목이 정상 표시된다.
