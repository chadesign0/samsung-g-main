# 오십견 증상 박스 순차 등장 디자인

## 목표

오십견 증상 섹션이 화면에 들어오면 네 개의 증상 박스를 위에서 아래 순서로 한 번씩 나타낸다.

## 동작

- 기존 섹션 스크롤 감지와 `.reveal.visible` 상태를 그대로 사용한다.
- 첫 박스는 섹션 등장 직후 시작하고, 다음 박스는 0.16초 간격으로 이어진다.
- 각 박스는 16px 아래에서 원래 위치로 이동하며 부드럽게 페이드인한다.
- 기존 감지 로직이 관찰을 해제하므로 애니메이션은 한 번만 실행된다.
- `prefers-reduced-motion` 환경에서는 모든 박스를 즉시 표시한다.

## 구현 범위

별도 JavaScript를 추가하지 않고 오십견 페이지 전용 CSS와 캐시 버전만 수정한다.
