# 내비게이션 스크롤 떨림 방지 설계

## 문제

데스크톱에서 스크롤이 `80px`을 넘으면 카테고리 내비게이션의 높이가 줄어든다. 이 레이아웃 변경으로 `scrollY`가 다시 `80px` 아래로 내려가면 접힘과 펼침이 반복되어 내비게이션이 떨린다.

## 해결 방식

- 데스크톱에서 펼쳐진 내비게이션은 `scrollY > 80`일 때 접는다.
- 일단 접힌 내비게이션은 `scrollY <= 8`에 도달할 때까지 접힌 상태를 유지한다.
- 모바일 뷰포트에서는 접힘 상태를 즉시 해제한다.
- 기존 헤더 호버 시 카테고리가 다시 나타나는 CSS 동작은 유지한다.

## 적용 범위

- 메인 페이지
- 퇴행성 무릎관절염 페이지
- 오십견 페이지
- 의료진 소개 페이지

## 검증

- 각 페이지에서 `80px` 부근을 한 번 스크롤했을 때 접힘 상태가 반복되지 않는지 확인한다.
- 스크롤을 최상단으로 되돌리면 카테고리가 한 번만 펼쳐지는지 확인한다.
- 헤더 호버와 모바일 메뉴가 기존처럼 작동하는지 확인한다.
