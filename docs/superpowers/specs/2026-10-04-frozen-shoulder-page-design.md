# 오십견 상세 페이지 디자인

## 목표

제공된 1920px 오십견 시안을 기존 삼성G정형외과 사이트에 새 질환 상세 페이지로 구현한다. 퇴행성 무릎관절염 페이지의 공통 구조와 상호작용을 유지하면서 어깨 질환에 맞는 이미지, 문구 및 증상 표현을 적용한다.

## 파일 구조

- 페이지: `pages/frozen-shoulder.html`
- 전용 스타일: `pages/frozen-shoulder.css`
- 전용 동작: `pages/frozen-shoulder.js`
- 이미지: `assets/subpages/frozen-shoulder/`
- 기존 로고, 국기, 상담 영역, 푸터 자산과 navbar 축소 동작은 재사용한다.

## 화면 구성

1. 공통 2단 헤더와 스크롤 시 카테고리 축소·hover 펼침 동작
2. 어깨 통증 이미지, 경로, 오십견 제목과 설명, 어깨질환 탭이 포함된 히어로
3. 네 가지 주요 원인을 카드로 보여주는 원인 섹션
4. 어깨 관절 해부 이미지와 네 가지 대표 증상 체크리스트로 구성한 증상 섹션
5. 약물치료, 물리·운동치료, 주사치료를 교차형 행으로 배치한 치료 섹션
6. 기존 상담문의와 푸터

## 이미지 배치

- 히어로: `노인의 어깨 통증과 엑스레이 관절염 표현.png`
- 원인 카드: `tip014j17090995.jpg`, `td00720004912.jpg`, `tc01500001327.jpg`, `tip115s19060185.jpg`
- 증상: `염증이 강조된 어깨 관절 해부도.png`
- 치료: 제공된 약물·물리치료·주사 이미지를 치료 종류에 맞게 사용한다.
- 원본 대용량 이미지는 화면 용도에 맞게 리사이즈 및 압축한 웹용 자산으로 저장한다.

## 상호작용

- 원인 카드는 호버·키보드 포커스·모바일 탭 시 설명을 표시한다.
- 섹션은 기존 스크롤 진입 페이드 효과를 유지한다.
- navbar는 데스크톱에서 스크롤 80px 이후 접히고 hover·키보드 포커스 시 펼쳐진다.
- 모바일에서는 기존 햄버거 메뉴를 유지한다.

## 연결

- 메인페이지, 무릎 페이지, 의료진 페이지의 `어깨질환` 메뉴를 새 오십견 페이지로 연결한다.
- 오십견 페이지에서는 `어깨질환`을 현재 메뉴로 표시한다.

## 반응형 및 검증

- 데스크톱은 시안의 1200px 중심 레이아웃을 따른다.
- 태블릿에서는 간격과 글자 크기를 줄이고, 모바일에서는 원인 카드 2열과 치료 행 1열을 사용한다.
- 모바일 증상 섹션은 이미지를 상단에 유지하고 체크리스트를 아래에 읽기 쉽게 배치한다.
- 로컬 서버에서 모든 파일의 HTTP 응답, 깨진 이미지, 가로 스크롤, 콘솔 오류를 확인한다.
