# 허리디스크 상세 페이지 디자인

## 목표

제공된 1920px 허리디스크 시안을 기존 삼성G정형외과 사이트의 `허리질환` 상세 페이지로 구현한다. 오십견 페이지의 구조와 상호작용을 재사용하되 허리디스크 전용 이미지, 문구, 증상 배치를 적용한다.

## 파일 구조

- 페이지: `pages/lumbar-disc.html`
- 전용 스타일: `pages/lumbar-disc.css`
- 전용 동작: `pages/lumbar-disc.js`
- 이미지: `assets/subpages/lumbar-disc/`
- 공통 로고, 국기, 상담문의, 푸터, navbar 축소 동작은 기존 자산과 패턴을 재사용한다.

## 화면 구성

1. 공통 2단 헤더와 스크롤 시 카테고리 축소·hover 펼침 동작
2. 허리 통증 이미지, 경로, 허리디스크 제목과 설명, 허리질환 탭이 포함된 히어로
3. `퇴행성 변화`, `잘못된 자세`, `반복되는 허리 부담`, `갑작스러운 충격`을 보여주는 네 개의 원인 카드
4. 허리 해부 이미지 위에 네 가지 증상 체크 박스를 2×2로 배치한 증상 섹션
5. 약물치료, 물리·운동치료, 주사치료를 교차형 행으로 배치한 치료 섹션
6. 기존 상담문의와 푸터

## 이미지 배치

- 히어로: `허리 통증을 보여주는 척추 의료 일러스트.png`
- 원인 카드: `tica1010038616.jpg`, `td0502t060312.jpg`, `cm08444945.jpg`, `pc004117503.jpg`
- 증상: `허리디스크와 신경 압박 해부학 이미지.png`
- 치료: 기존 `약물치료.png`, `물리,운동치료.png`, `주사치료.png`를 재사용한다.
- 원본 대용량 이미지는 화면 용도에 맞게 리사이즈·압축한 웹용 자산으로 복사한다.

## 문구와 탭

- 히어로 제목은 `허리디스크`, 부제는 `편안한 일상을 위한 맞춤 허리 진료`로 한다.
- 허리질환 탭은 `허리디스크`를 활성화하고 나머지는 허리질환 이름으로 구성한다. 시안에 남아 있는 무릎질환 탭 문구는 사용하지 않는다.
- 치료 문구는 허리 통증, 신경 압박, 자세 교정과 운동 회복에 맞게 작성한다.

## 상호작용

- 원인 카드는 hover·키보드 포커스·모바일 탭 시 설명을 표시한다.
- 원인 카드와 증상 체크 박스는 화면 진입 시 위에서부터 순서대로 한 번 나타난다.
- navbar는 데스크톱에서 스크롤 80px 이후 접히고 hover·키보드 포커스 시 펼쳐진다.
- 모바일에서는 기존 햄버거 메뉴를 유지하며 `prefers-reduced-motion`에서는 모든 요소를 즉시 표시한다.

## 연결

- 메인, 무릎, 오십견, 의료진 페이지의 `허리질환` 메뉴를 `lumbar-disc.html`로 연결한다.
- 허리디스크 페이지에서는 `허리질환` 메뉴를 현재 페이지로 표시한다.
- 푸터의 척추센터 링크도 새 허리디스크 페이지로 연결한다.

## 반응형 및 검증

- 데스크톱은 시안의 1200px 중심 레이아웃을 따른다.
- 태블릿에서는 간격과 글자 크기를 줄이고 모바일에서는 원인 카드를 2열, 증상 박스를 1열, 치료 행을 1열로 배치한다.
- 로컬 서버에서 모든 파일의 HTTP 응답, 이미지 로딩, 카드 상호작용, 순차 애니메이션, navbar, 모바일 가로 스크롤, 콘솔 오류를 확인한다.
