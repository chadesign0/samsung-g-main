# Navbar 통일 디자인

## 기준

퇴행성 무릎관절염 페이지의 navbar를 사이트 공통 기준으로 사용한다. 해당 페이지는 변경하지 않고 메인페이지와 의료진 소개 페이지를 동일한 구조와 크기로 맞춘다.

## 적용 범위

- 상단 유틸리티 영역 높이, 로고, 검색창, 언어 선택, 로그인·회원가입, 메뉴 버튼 크기
- 하단 주 메뉴 높이, 글자 크기, 항목 간격, 호버·키보드 포커스 표시
- `병원소개 / 무릎질환 / 어깨질환 / 허리질환 / 고객센터` 카테고리와 각 페이지에 맞는 상대 경로
- 모바일에서 64px 헤더와 화면 전체 슬라이드 메뉴 동작

## 페이지별 현재 위치

- 퇴행성 무릎관절염 페이지는 `무릎질환`을 현재 항목으로 표시한다.
- 의료진 소개와 메인페이지는 별도의 현재 항목을 강제하지 않는다.

## 구현 방식

현재 정적 페이지 구조를 유지하고 각 HTML·CSS의 navbar 부분만 동기화한다. 새로운 공통 컴포넌트나 빌드 과정은 추가하지 않는다.

## 검증

- 세 페이지의 데스크톱 navbar 높이, 크기, 카테고리 순서를 비교한다.
- 메인페이지와 의료진 소개 페이지에서 모든 navbar 링크가 올바르게 이동하는지 확인한다.
- 모바일 메뉴가 열리고 닫히며 배경 스크롤이 잠기는지 확인한다.
- 브라우저 콘솔 오류와 가로 스크롤이 없는지 확인한다.
