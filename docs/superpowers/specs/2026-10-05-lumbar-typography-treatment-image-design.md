# 허리디스크 증상 글꼴 및 치료 이미지 수정

## 목표

허리디스크 페이지의 증상 박스 글꼴을 다른 질환 페이지와 통일하고, 물리·운동치료 행의 크기를 다른 치료 행과 동일하게 맞춘다.

## 변경 범위

- 데스크톱 증상 박스 글꼴을 오십견 페이지와 같은 `clamp(16px, 1.25vw, 24px)`로 변경한다.
- 기존 모바일 글꼴 크기와 1열 배치는 유지한다.
- 폴더에 추가된 `물리치료.png`를 허리디스크 전용 치료 자산으로 사용한다.
- 새 이미지의 원본 규격 `604×278`을 유지해 약물치료·주사치료 행과 같은 높이로 표시한다.
- 기존 대형 물리치료 JPG는 새 PNG로 대체한다.
- CSS 캐시 버전을 올려 변경 사항을 즉시 반영한다.

## 검증

- 데스크톱에서 네 증상 박스 글꼴 크기가 오십견 페이지와 같은지 확인한다.
- 세 치료 행의 이미지 및 행 높이가 동일한지 측정한다.
- 모바일 가로 넘침, 이미지 누락 및 브라우저 콘솔 오류를 확인한다.
