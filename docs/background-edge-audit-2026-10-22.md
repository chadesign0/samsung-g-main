# 배경 이미지 가장자리 점검

작업일: 2026-10-22. 로컬 변경만 적용했으며 커밋·push·배포는 하지 않음.

## 범위와 수정

CSS의 배경 이미지 및 JS에서 지정하는 hero/criteria/process 이미지 93개를 수집해 원본 픽셀의 네 방향 가장자리를 검사했다. 사진 크기 후보 91개, 장식·소형 이미지 2개다. 전체 74개 HTML 페이지는 별도의 소스/DOM 테스트로 검사했다.

| 실제 사용 구간 | 확인된 원인 | 보정 |
| --- | --- | --- |
| 메인 치료 소개 | 흐림 효과가 포함된 반투명 테두리, 원본에서 사방 20px 안쪽부터 완전 불투명 | 배경 레이어를 사방 3% 확장하고 부모에서 자름 |
| 허리 질환 6개 상단 | 각 원본 마지막 1px 행이 불완전 불투명 | 배경 레이어 하단 0.5% 확장 |
| 무릎 질환 7개 증상 영역 | 원본 상단 3px 행이 불완전 불투명 | 배경 레이어 상단 1% 확장 |
| 고관절 점액낭염 상단 | 원본 왼쪽 1px 열이 투명 | 해당 질환만 배경 레이어 사방 0.2% 확장 |
| 허리 질환 6개 증상 영역 — 앞선 수정 유지 | 원본 하단 11px 투명 행 및 인접 1px 불완전 불투명 행 | 배경 레이어 하단 2% 확장 |

배경 레이어만 확장해 텍스트·내용·영역 높이는 바꾸지 않았다. 모바일 무릎 배경의 기존 가로 위치 58%도 유지했다. 해당 CSS를 사용하는 15개 페이지의 직접 참조 캐시 버전을 갱신했다.

## 수정하지 않은 항목

- 메인 의료진의 회색 텍스처: 이미지 전체 알파 102인 의도적인 반투명 디자인.
- 아킬레스건염 상단: 하얀 바닥이 사진 구성에 포함된 자연스러운 배경.
- 구형 frozen-shoulder / knee-osteoarthritis CSS의 가장자리 후보 2개: 현재 HTML에서 사용하지 않는 구형 이미지이므로 보정 대상에서 제외.
- 장식용 로고·아이콘 및 기존 경계선은 보존.

픽셀 검사 후보 14개 가운데 실제 사용 중인 가장자리 문제는 10개 이미지다. 이 중 허리 증상 배경은 앞선 수정이며 이번에는 추가 9개 이미지를 보정했다. 수정 전후 93개 원본 이미지의 SHA-256이 모두 동일하다.

## 검증과 한계

- `python tests/audit-background-assets.py`: 읽기 전용 원본 픽셀 검사. 원본을 수정하지 않으므로 보정 후에도 원본의 가장자리 후보는 그대로 보고된다.
- `python tests/background-edge-coverage.py`: 10개 이미지의 완전 불투명 내부 경계 확인, 320개 영역 크기 조합의 cover 기하 검증, 15개 페이지의 캐시 참조 확인 통과.
- `node tests/lumbar-background.cjs`: 기존 허리 증상 배경의 원본 해시, 28개 영역 크기 조합, 6개 페이지 캐시 참조 확인 통과.
- `node tests/site-smoke.cjs`: 74개 페이지, 로컬 참조 7,893개, 검증 9,056개 통과.
- `node tests/day-hospital-animation.cjs`: 기존 낮병동 애니메이션 회귀 검사 통과.
- `git diff --check`: 오류 없음.

자동 브라우저의 로컬 접근이 저장된 정책에 의해 차단되어 실제 브라우저 화면 캡처·실기기 렌더링은 검증하지 못했다. 우회하지 않았으며 위 결과는 원본 픽셀·CSS 기하·소스/DOM 검사 결과다. 로컬 서버는 http://127.0.0.1:8085/ 에서 실행 중이다.
