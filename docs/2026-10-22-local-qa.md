# 로컬 점검·보완 기록

작업일: 2026-10-22 (Asia/Seoul)

## 이번에 완료한 범위

- 로컬 서버 재시작: http://127.0.0.1:8085/ (로컬 PC에서만 접속 가능).
- 메인 검색 설명의 시안 문구를 실제 안내 범위에 맞게 수정.
- 로그인·회원가입의 잘못된 페이지 내 이동 제거. 미연결 정책 문서, 언어 선택, 미완성 통합 검색에 안내 메시지 제공.
- 수액치료의 자세히 보기가 원스톱 진료로 잘못 이동하지 않도록 차단. 다른 정상 탭으로 돌아오면 안내 상태 해제.
- 준비 중인 항목은 실제 서비스로 구현되었다고 표시하지 않음. 약관 원고·회원 인증·상담 저장 기능은 생성하지 않음.
- 닫힌 데스크톱 메뉴를 inert 처리하여 숨은 링크의 키보드 접근 방지.
- 모바일 전체 메뉴에서 Tab 순환·Esc 닫기·초점 복귀 보완.
- 공통 파일과 연결 CSS의 캐시 버전을 일괄 갱신.
- 병원 원고·금액·연락처·원본 이미지·기존 레이아웃은 유지.

## 검증

- `tests/site-smoke.cjs`: 전체 72개 페이지, 로컬 파일 참조 7,330개, 검증 항목 7,929개 통과.
- 모든 페이지에서 동적 본문 생성, 공통 하단 적용 범위, 임시 링크 상태 및 로컬 파일 존재 여부 확인.
- 메인 임시 버튼 안내, 수액치료/정상 탭 전환, 데스크톱 Esc 및 모바일 Tab/Esc, 목 원인 카드 재클릭 닫기, 모바일 공지사항 colspan/검색 확인.
- 테스트는 jsdom을 사용하는 네트워크 없는 소스/DOM 테스트임. jsdom을 별도 설치하고 `NODE_PATH`에서 찾을 수 있게 한 뒤 `node tests/site-smoke.cjs`로 실행.
- 자동 브라우저는 저장된 권한 설정으로 로컬 주소 접근이 거부됨. 다른 브라우저나 우회 경로를 사용하지 않았으며 실제 픽셀 배치·실기기 동작은 미검증.

## 바로 이어서 확인할 사항

- PC·모바일 화면의 여백·겹침·폰트·이미지 크롭·하단 고정 메뉴: 사용자가 로컬 화면에서 확인하거나 자동 브라우저 접근이 허용된 뒤 점검.
- 약관·개인정보처리방침·환자 권리장전: 병원 승인 원문과 실제 게시 목적지 필요.
- 상담 글쓰기·회원 기능: 저장 서버, 개인정보 처리 방식, 운영/답변 담당과 인증 방식 결정 필요. 민감한 상담 내용을 브라우저 로컬 저장으로 임의 구현하지 않음.
- 수액치료: 실제 운영 원고·항목·사진과 상세 페이지 구성 확정 필요.
- 비급여 금액·경력·진료 설명: 병원 최종 승인 자료 필요.
- 실제 병원 블로그/예약/상담 채널 URL 확인, 언론보도 실제 기사 제공 및 운영 정책 결정 필요.
- 큰 시설/원인 이미지의 전송 용량 최적화는 원본 보존·출력 크기·화질 대조 검수와 함께 별도 진행.

이번 작업은 로컬 변경이며 커밋·push·GitHub Pages 재배포는 하지 않았음.
