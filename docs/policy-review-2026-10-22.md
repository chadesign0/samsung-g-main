# 이용약관·개인정보처리방침 검토 기록

작성 기준: 2026-10-22, 삼성G정형외과 현재 로컬 홈페이지 및 사용자 제공 이미지 2개.

## 결과물과 문서 상태

- `pages/terms.html`: 이용약관 전문. `assets/policies/terms-draft.txt`에서 동일한 전체 텍스트 제공.
- `pages/privacy-policy.html`: 개인정보처리방침 전문 초안. `assets/policies/privacy-draft.txt`에서 동일한 전체 텍스트 제공.
- 두 페이지는 이미지가 아닌 HTML 텍스트이며, 선택·복사·검색·인쇄가 가능함. PC·모바일용 본문 크기·행간·목차·내려받기 링크 적용.
- 모든 페이지의 공통 푸터와 메인 정적 푸터의 두 링크를 연결. 환자 권리장전은 이번 요청 범위가 아니므로 미연결 상태 유지.
- 두 문서는 **병원 검토 전 초안**으로 표시하고 검색 수집 제외용 `noindex, nofollow` 적용. 시행일은 임의 확정하지 않음. 검색 제외 설정은 접근 통제가 아니며, 승인 전 공개 배포하지 않는 것이 필요함.
- 원본 이미지의 문장을 그대로 전사한 파일이 아니라, 현재 홈페이지에 맞게 다시 작성한 **개정 전문**임. 원본 파일은 수정하지 않음.

## 원본에서 수정·제외한 사항

1. 이용약관의 다른 병원명 ‘클래스병원’을 삼성G정형외과로 변경하고 본원·회사 등 혼용 정리.
2. 개인정보처리방침 이미지의 실제 본문은 이용계약·회원·게시물·면책 등 이용약관 내용임. 해당 내용을 개인정보 방침으로 재사용하지 않고 역할에 맞게 별도 작성.
3. 현재 구현되지 않은 회원가입·ID·비밀번호·탈퇴·재가입과 유료 서비스 조항은 현재 제공 중인 서비스로 표시하지 않음. 향후 기능 도입 시 별도 안내하도록 정리.
4. 홈페이지 열람 시간과 진료·상담 가능 시간을 구분. 온라인 상담 24시간 제공·회신을 보장하지 않음.
5. 무응답을 약관 변경에 대한 포괄 동의로 간주하거나, 이용약관만으로 광고·학술·업무제휴 목적의 개인정보 공유를 허용하는 문구는 제외.
6. 모든 손해에 대한 일률적 면책, 이용자에게 부당하게 불리할 수 있는 병원 소재지 법원의 전속관할 조항 대신 관계 법령과 민사소송법상 관할 규정에 따르도록 작성.
7. 원본의 과거 시행일(2011-01-01)과 미완성 안내 문구를 새 문서의 시행일로 승계하지 않음.
8. 홈페이지에 이미 사용 중인 대표자·주소·사업자등록번호·대표전화·이메일·팩스 유지. 이메일은 현재 코드의 `samsungggos@naver.com` 기준이며 병원에서 최종 확인 필요.
9. 메인의 JS 실행 전 정적 푸터에 남아 있던 예전 대표자·개인 휴대전화 표기를 현재 공통 푸터 기준으로 정리. 대표자는 이상현으로 통일하고 별도 개인 휴대전화 표기는 제거.

## 확인된 기술적 사실과 한계

- 현재 소스에 회원 인증·상담 접수 저장·온라인 예약 접수·결제 기능 없음.
- 게시판 검색은 현재 페이지에서만 처리하며 검색어 전송·별도 저장 코드 없음.
- 병원 작성 코드에서 직접 쿠키·광고 분석 추적 코드를 실행하는 기능은 확인되지 않았으나, 호스팅·외부 삽입 요소의 정보 처리까지 없다고 단정할 수 없음.
- 공개 사이트 호스팅은 GitHub Pages. Google Fonts 요청과 Google 지도 삽입 사용 확인.
- GitHub Pages 방문자의 IP 보안 로그는 공식 문서로 확인. Google Fonts 요청 및 삽입된 지도 등 Google 서비스의 정보 처리 가능성은 공식 자료 참고.
- 진료기록·보험청구·CCTV·전화 녹음·이메일 보관, 실제 관리자·수탁자 계약 및 서버 로그는 소스만으로 확인할 수 없음.
- 외부 서비스의 사용 사실과 국내법상 위탁·제3자 제공·국외 이전의 법적 분류는 다를 수 있으므로 계약·설정에 따른 검토가 필요함.

## 확정 전에 필요한 병원 확인

- 개인정보 보호책임자 지정 여부와 성명·직책 또는 책임 부서, 열람·고충처리 담당 및 연락처.
- 업무별 개인정보 항목·목적·법적 근거·보유기간과 실제 파기 방법.
- 홈페이지 제작·유지보수·호스팅·이메일 등 수탁자와 재위탁, 제3자 제공 및 국외 이전의 실제 내역.
- 내부 보호조치, 권리행사 및 이의신청 절차, 외부 서비스 설정.
- 진료업무 전반의 방침과의 통합 또는 명확한 적용 범위·별도 방침 안내.
- 최종 시행일 및 기존 승인 방침이 있다면 이전 문서·변경 이력.

사용자가 ‘별도로 전달받은 내용은 없으므로 임의 작성’을 요청했으나, 확인되지 않은 책임자·보유기간·계약을 실제 사실처럼 만들지 않았음. 본 초안은 최종 법률 검토나 병원의 법적 적합성 보증을 대신하지 않음.
